Studia

School Management System

Studia is a web-based school management system developed to simplify academic and administrative operations. The platform provides modules for student records, staff management, subject allocation, result computation, promotions, and role-based access control. As the project lead, I worked on frontend implementation, backend integration, testing, debugging, deployment, and continuous improvement of the system. The application is currently deployed and used by a Nigerian secondary school.

Technologies: PHP • MySQL • JavaScript • HTML • CSS
